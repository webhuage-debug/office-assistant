# 群晖 NAS 搭建 115 网盘 + Emby + STRM + 302 直链播放方案

```c++
apt update -y
apt install curl

## 一、技术原理

这套方案的核心目标是：

```text
视频文件放在 115 网盘
Emby 只负责海报墙和媒体库
本地只保存 STRM 文件
播放时通过 302 跳转到 115 CDN
播放器直接从 115 CDN 拉取视频
NAS 不负责视频中转
```

最终播放链路：

```text
用户在 Emby 点播放
        ↓
Emby 读取本地 STRM 文件
        ↓
go-emby2openlist 接管播放请求
        ↓
读取 STRM 中的 OpenList 地址
        ↓
OpenList 获取 115 真实直链
        ↓
go-emby2openlist 返回 302 / 307 跳转
        ↓
播放器直接访问 115 CDN
```

各组件作用：

```text
OpenList
负责登录 115 网盘，读取 115 文件，并生成 115 下载直链。

SmartStrm
负责把 115 网盘里的视频生成本地 .strm 文件。

Emby
负责媒体库、海报墙、刮削、播放记录。
只扫描本地 STRM 目录，不直接扫描 115 网盘。

go-emby2openlist
负责接管 Emby 的播放请求，把 OpenList 地址解析成 115 CDN 直链，并返回 302 / 307 跳转。
```

重要原则：

```text
STRM 里面保持 OpenList 的 5244 地址
不要把 STRM 里面的地址改成 8095

go-emby2openlist 入口是 8095
但它不是直接提供 /d/115 文件服务的
它是通过接管 Emby 播放请求来完成 302 跳转
```

正确的 STRM 内容示例：

```text
http://10.0.0.128:5244/d/115/测试片源/xxx.mp4?sign=xxxx
```

不要改成：

```text
http://10.0.0.128:8095/d/115/测试片源/xxx.mp4?sign=xxxx
```

## 二、搭建顺序

推荐搭建顺序：

```text
1. 创建统一项目目录
2. 部署 OpenList
3. 在 OpenList 中添加 115 网盘
4. 部署 Emby
5. 初始化 Emby，但先不要添加正式媒体库
6. 部署 SmartStrm
7. SmartStrm 连接 OpenList
8. SmartStrm 生成测试 STRM
9. Emby 添加测试媒体库
10. 部署 go-emby2openlist
11. 通过 8095 入口访问 Emby 并测试播放
12. 确认日志显示跳转到 115 CDN
13. 再分批生成正式电影库和电视剧库
```

## 五、部署 OpenList

### 说明

OpenList 负责登录 115 网盘。后续 SmartStrm 通过 OpenList 读取 115 文件列表，go-emby2openlist 也通过 OpenList 获取 115 直链。

OpenList 访问地址：

```text
http://10.0.0.128:5244
```

### 命令

```bash
sudo -i

cd /volume1/docker/emby115

cat > docker-compose.yml <<'EOF'
services:
  openlist:
    image: openlistteam/openlist:latest
    container_name: openlist
    restart: unless-stopped
    user: "0:0"
    ports:
      - "5244:5244"
      - "5245:5245"
    volumes:
      - /volume1/docker/emby115/openlist/data:/opt/openlist/data
    environment:
      - TZ=Asia/Shanghai
      - UMASK=022
EOF

docker compose pull

docker compose up -d

docker ps

docker logs --tail=50 openlist
```

### OpenList 面板需要完成的事情

打开：

```text
http://10.0.0.128:5244
```

需要完成：

```text
1. 初始化管理员账号
2. 登录 OpenList 后台
3. 进入：管理 → 存储 → 添加
4. 驱动选择：115 网盘
5. 挂载路径填写：/115
6. 登录 115 账号
7. 保存
8. 确认可以打开：http://10.0.0.128:5244/115
```

建议 115 目录结构：

```text
/115/测试片源
/115/电影
/115/电视剧
```

## 六、部署 Emby

### 说明

Emby 负责海报墙、媒体库和播放记录。Emby 不直接扫描 115 网盘，只扫描本地 STRM 目录。

Emby 访问地址：

```text
http://10.0.0.128:8096
```

如果需要走 go-emby2openlist 代理入口，后面使用：

```text
http://10.0.0.128:8095
```

### 命令

这一步会在原来的 `docker-compose.yml` 里追加 Emby 服务。

```bash
sudo -i

cd /volume1/docker/emby115

cat >> docker-compose.yml <<'EOF'

  emby:
    image: emby/embyserver:latest
    container_name: emby
    restart: unless-stopped
    user: "0:0"
    devices:
      - /dev/dri:/dev/dri
    ports:
      - "8096:8096"
      - "8920:8920"
    volumes:
      - /volume1/docker/emby115/emby/config:/config
      - /volume1/docker/emby115/strm:/media/strm
    environment:
      - TZ=Asia/Shanghai
      - UID=0
      - GID=0
EOF

docker compose pull emby

docker compose up -d emby

docker ps

docker exec -it emby ls -l /dev/dri
```

### Emby 面板需要完成的事情

打开：

```text
http://10.0.0.128:8096
```

需要完成：

```text
1. 初始化 Emby 管理员账号
2. 暂时不要添加正式媒体库
3. 进入控制台
4. 进入媒体库设置
5. 关闭“保存媒体图片到媒体文件夹中”
6. 确认 Emby 元数据、海报、缓存都保存在 /config，也就是：
   /volume1/docker/emby115/emby/config
```

硬解检查：

```text
如果 docker exec -it emby ls -l /dev/dri 能看到 card0 和 renderD128，说明 Emby 容器已经识别到核显。
```

## 七、部署 SmartStrm

### 说明

SmartStrm 负责把 115 网盘里的视频生成本地 STRM 文件。

SmartStrm 访问地址：

```text
http://10.0.0.128:8024
```

注意：SmartStrm 连接 OpenList 时，必须连接 5244。

```text
SmartStrm → OpenList 5244 → 读取 /115 文件列表
```

不要让 SmartStrm 连接 8095，8095 是播放代理入口，不负责列目录。

### 命令

```bash
sudo -i

cd /volume1/docker/emby115

cat >> docker-compose.yml <<'EOF'

  smartstrm:
    image: cp0204/smartstrm:latest
    container_name: smartstrm
    restart: unless-stopped
    ports:
      - "8024:8024"
    volumes:
      - /volume1/docker/emby115/smartstrm/config:/app/config
      - /volume1/docker/emby115/smartstrm/data:/app/data
      - /volume1/docker/emby115/strm:/strm
    environment:
      - TZ=Asia/Shanghai
      - ADMIN_USERNAME=admin
      - ADMIN_PASSWORD=admin123
EOF

docker compose pull smartstrm

docker compose up -d smartstrm

docker ps

docker logs --tail=50 smartstrm
```

### SmartStrm 面板需要完成的事情

打开：

```text
http://10.0.0.128:8024
```

登录：

```text
用户名：admin
密码：admin123
```

添加存储：

```text
存储名称：openlist115
驱动：OpenList / AList
OpenList 地址：http://10.0.0.128:5244
Token：填写 OpenList 的 Token
强制刷新目录：不勾选
替换 STRM 地址：留空
```

非常重要：

```text
替换 STRM 地址不要填写 8095
保持留空
让 STRM 里面生成 5244 地址
```

正确 STRM 内容示例：

```text
http://10.0.0.128:5244/d/115/测试片源/xxx.mp4?sign=xxxx
```

创建测试任务：

```text
任务名称：test
使用存储：openlist115
扫描路径：/115/测试片源
保存目录：/strm/test
目录时间检查：第一次关闭
增量生成模式：第一次关闭
```

第一次跑通后，再考虑开启：

```text
目录时间检查：开启
增量生成模式：开启
```

### 测试 STRM 是否生成成功

```bash
find /volume1/docker/emby115/strm -name "*.strm" | head -5

查看 STRM 内容：

```bash

```

正确结果应该包含：

```text

## 九、部署 go-emby2openlist

### 说明

go-emby2openlist 负责接管 Emby 播放请求，并把 STRM 里的 OpenList 地址解析成 115 CDN 直链。

代理入口：

```text
http://10.0.0.128:8095
```

后续播放时，建议从 8095 进入 Emby：

```text
http://10.0.0.128:8095
```

注意：

```text
STRM 文件内容仍然保持 5244 地址
不要把 STRM 改成 8095
不要设置 5244 => 8095 的 path-map
```

### 命令

执行前，需要先拿到 OpenList Token。

OpenList Token 获取位置：

```text
OpenList 后台 → 管理 → 设置 → 其他 → 令牌 / Token
```

把下面命令中的：

```text
OPENLIST_TOKEN_HERE
```

替换成你的 OpenList Token。

```bash
sudo -i

cd /volume1/docker/emby115

cat > /volume1/docker/emby115/go-emby2openlist/config.yml <<'EOF'
emby:
  host: http://10.0.0.128:8096
  mount-path: /media/strm
  proxy-error-strategy: origin
  images-quality: 100
  strm:
    path-map:
    internal-redirect-enable: true
    download-strategy: 302
  local-media-roots: []

openlist:
  host: http://10.0.0.128:5244
  token: OPENLIST_TOKEN_HERE
  local-tree-gen:
    enable: false

path:
  emby2openlist:
    - /media/strm/test:/115/测试片源
    - /media/strm/电影:/115/电影
    - /media/strm/电视剧:/115/电视剧

cache:
  enable: true
  expired: 1d

ssl:
  enable: false

log:
  disable-color: false
EOF

cat > /volume1/docker/emby115/go-emby2openlist/docker-compose.yml <<'EOF'
services:
  go-emby2openlist:
    image: ambitiousjun/go-emby2openlist:v2.7.0
    container_name: go-emby2openlist
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
      - GIN_MODE=release
    ports:
      - "8095:8095"
      - "8094:8094"
    volumes:
      - /volume1/docker/emby115/go-emby2openlist/config.yml:/app/config.yml
      - /volume1/docker/emby115/go-emby2openlist/ssl:/app/ssl
      - /volume1/docker/emby115/go-emby2openlist/custom-js:/app/custom-js
      - /volume1/docker/emby115/go-emby2openlist/custom-css:/app/custom-css
      - /volume1/docker/emby115/go-emby2openlist/lib:/app/lib
EOF

cd /volume1/docker/emby115/go-emby2openlist

docker compose pull

docker compose up -d

docker ps

docker logs --tail=50 go-emby2openlist
```

### 如果忘记替换 OpenList Token

```bash
sudo -i

cd /volume1/docker/emby115/go-emby2openlist

sed -i 's#token: OPENLIST_TOKEN_HERE#token: 你的OpenListToken#g' config.yml

docker compose restart

docker logs --tail=50 go-emby2openlist
```

## 十、关键配置检查

### 检查 STRM 是否为 5244 地址

```bash
cat "$(find /volume1/docker/emby115/strm -name '*.strm' | head -1)"
```

正确应该是：

```text
http://10.0.0.128:5244/d/115/...
```

错误示例：

```text
http://10.0.0.128:8095/d/115/...
```

如果已经错误替换成 8095，恢复成 5244：

```bash
find /volume1/docker/emby115/strm -name "*.strm" -type f \
  -exec sed -i 's#http://10.0.0.128:8095#http://10.0.0.128:5244#g' {} \;
```

### 检查 go-emby2openlist 不能有 5244 到 8095 映射

```bash
grep -n "path-map\|5244\|8095\|internal-redirect\|download-strategy" /volume1/docker/emby115/go-emby2openlist/config.yml
```

正确状态应该类似：

```text
path-map:
internal-redirect-enable: true
download-strategy: 302
host: http://10.0.0.128:5244
```

不应该出现：

```text
http://10.0.0.128:5244/d/115 => http://10.0.0.128:8095/d/115
```

如果出现，删除这行后重启：

```bash
sed -i '/5244\/d\/115 => .*8095\/d\/115/d' /volume1/docker/emby115/go-emby2openlist/config.yml

cd /volume1/docker/emby115/go-emby2openlist

docker compose restart
```

## 十一、如何确认是走 115 CDN 播放

### 方式一：测试 OpenList 是否返回 302

先找一个 STRM 文件：

```bash
cat "$(find /volume1/docker/emby115/strm -name '*.strm' | head -1)"
```

复制里面的 5244 地址，然后执行：

```bash
curl -I "这里粘贴 STRM 里面的完整 5244 地址"
```

正确结果应该类似：

```text
HTTP/1.1 302 Found
Location: https://cdnxxx.115cdn.net/...
```

只要 `Location` 是 `115cdn.net`，就说明 OpenList 已经拿到了 115 CDN 直链。

### 方式二：从 8095 入口播放并看 go-emby2openlist 日志

用这个地址进入 Emby：

```text
http://10.0.0.128:8095
```

播放一个视频后执行：

```bash
docker logs --tail=100 go-emby2openlist | grep -iE "重定向|redirect|307|302|115cdn|stream|/d/115"
```

正确日志应该出现类似：

```text
正在尝试内部重定向, originLink: [http://10.0.0.128:5244/d/115/...]
[SUCCESS] 重定向 strm: https://cdnxxx.115cdn.net/...
307 | GET /emby/videos/xx/stream
```

出现这些内容说明：

```text
Emby 播放请求已经被 go-emby2openlist 接管
STRM 中的 5244 地址被解析
最终重定向到了 115 CDN
```

### 方式三：观察 NAS 上传流量

正确的 302 直链播放：

```text
NAS 上传流量很低
客户端直接从 115 CDN 下载
```

如果 NAS 上传很高，说明可能还是 NAS 在中转。

## 十二、正式电影库很多时怎么做

电影很多时，不要一次性全库生成。

推荐分批：

```text
/115/电影/A-F
/115/电影/G-L
/115/电影/M-R
/115/电影/S-Z
/115/电影/中文
/115/电视剧
```

```text
任务1：
扫描路径：/115/电影/A-F

任务2：
扫描路径：/115/电影/G-L

```text

```text

```text

```text
